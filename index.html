問い 1 / 波がそろうとは、どういうことか

ピークってそもそもなんなん？

狭い 2.5 Å広い 6 Å
12°45°
検出器に届いた波2つの波と、その合計

ピークとは「届いた波どうしが強め合った角度」のこと。角度が少しずれると、下の面の波の遠回りが波長の整数倍から外れ、山と谷が混ざって消えていく。遠回りの区間には波長1つぶんごとの目盛りを刻んであるので、「何波長分か」は数えられる。

答え：ピークは、規則正しい積み重なりの「そろう角度」にだけ立つ。面が等間隔に積み重なっているからこそ、遠回りが全ペアで同じになり、強め合う角度が1つに定まる。

並べる面の数
等間隔バラバラ

乱れを上げると、面と面の間隔が1枚ごとにランダムにずれる。原子そのものは同じでも、「規則正しさ」が崩れる。

問い 2 / その角度の決まり方

ある角度って、どう決まってるん？

結晶の中（舞台）1組の面と、そろう角度
狭い広い

つまみを動かして離すと、動かす前のピークが灰色で残る（基準）。位置の「移動」は、基準と並べて初めて見える。

X線の届き方灰色 = 前の条件

答え：ピークの横の位置は、「波がそろう角度」そのもの。面間隔が狭い → そろう角度は大きい。横軸の 2θ は、検出器が直進方向からどれだけ回ったか、その角度をそのまま書いているだけ。
そもそも「2θ」って何の角度？

2θ は、入ってきたX線と、散乱されたX線のなす角度。装置が測って、グラフの横軸になるのはこの 2θ の方です。一方、ブラッグの式 2d sin θ = λ の θ は、X線と結晶の面のなす角度で、2θ のちょうど半分。式の θ とグラフの 2θ が別物なのは、このためです。

ここから、よくあるブラッグの図につながる
  • 舞台は、平行な面が間隔 d で積み重なった結晶
  • 上の面で散乱した波と、1つ下の面で散乱した波を比べる
  • 下の面の波は、行きと帰りで少し遠回りする（図の紫）。遠回りの合計は 2d sinθ
  • この遠回りが波長 λ の整数倍（nλ）にちょうど等しいとき、山と山が重なって強くなる → 2d sinθ = nλ（ブラッグの式）
  • 角度が少しずれると、何百枚もの面の波が山と谷で混ざって消える。だからピークは特定の角度にだけ立つ

実験01で「道のり差 ○波長」と見ていたのは、この遠回りのことです。この入口の計算も、鏡のような反射を仮定せず、入射と散乱の両方の道のりから波のずれを出しています。

次の問い：なんで複数ピーク出るん？ →
問い 3 / ピークの正体は面の組

なんで複数ピーク出るん？

結晶の中（舞台）光った面の組が、ピークを出す
面の組を、1つずつ足していく間隔の広い順

塩みたいに単純な結晶でも、測るとピークは1本じゃない。結晶の中には、向きも間隔も違う面の組がたくさんある。足すボタンで組を増やすと、その組のピークがチャートに増えていく。さらに、最初の組と同じ向きで間隔が半分・3分の1の組もあって、それは高い角度にもう何本かピークを出す（金色のボタン）。

塩 NaCl は2種類の原子からなるため、ピークの高さはこのモデルでは近似。位置と「出る・出ない」の並びが本題。

同じ結晶から出る全ピーク足した面の組の分だけ

答え：ピークが多いのは、面の組が多いから。向きも間隔も違う組がたくさんあって、それぞれが自分のそろう角度にピークを立てる。同じ向きで間隔が半分の組は、高い角度にもう1本出す。「面の組」という考え方が、ピークの本数と位置をまとめて説明する。

X線が見るのは、原子核ではなく原子のまわりの電子の雲。電子が多い原子ほど強く散らす（深掘りの「そもそも、X線は原子の何を見ている？」につながる話）。

答え：ピークの高さは、その面の組で波がどれだけ強め合うかで決まる。もとになる1つ1つの散乱の強さは、原子の電子の多さで決まる。そして中央に原子が入ると、面の組によっては波がきれいに打ち消し合って、ピークが消える。位置は動かないのに、消える。

そもそも、X線は原子の何を見ている？

X線を散らすのは、原子核ではなく、原子のまわりに広がる電子の雲です。核は重すぎて、X線にはほぼ応答しません。だから、電子が多い原子ほど強く散らし、電子が1個しかない水素はほとんど見えません。

このページで描く原子の丸は、この電子の雲の模式図です。実験03の「中央の原子の入り具合」も、そこにどれだけ電子があるかの話として読めます。

透過法と反射法、2θはどの角？

測り方には大きく2つの配置があります。でも 2θ の定義はどちらも同じで、入射ビームと回折ビームのなす角度。違うのは、試料と検出器の置き方です。

反射法：平板の試料にX線を当て、線源と同じ側で受ける。ピークに寄与するのは、試料の表面と平行な面。線源と検出器は試料を中心に対称に動き、試料が θ 傾くとき検出器は 2θ の位置に来る。平板に載せて手軽に測れるため広く普及し、品質管理の現場でも定番の配置。

透過法：X線に試料を通り抜けさせ、後ろの検出器で受ける。回折したX線は入射ビームを軸とする円錐（コーン）状に広がる。2次元検出器にはリングとして写り、検出器を動かして走査するタイプでは、そのコーンを横切りながら角度ごとの強さを拾っていく。2θ は、直進してきたビームの中心から測った角度。試料がごく少量でも測れ、結晶の向きの偏り（配向）の影響も受けにくい。キャピラリーやウェルプレートで多検体を測る形もあり、研究開発の結晶多形スクリーニングなどでは、こちらが主流の現場も多い。

実務編：ピークの強さが合わない？ — 配向性

このページのモデルは、粉末の結晶の向きがバラバラ（ランダム）という前提です。実務では、この前提が崩れることがあります。

針状や板状の結晶は、平板に載せると寝て向きが揃います（配向）。反射法でピークに寄与するのは試料表面と平行な面だけなので、揃った面のピークだけが異常に強く、ほかが弱くなる。ピークの位置は合っているのに、強さの並びが参照パターンと合わない——実務ではそういう困り方をします。

対策は、粉砕して結晶の形を崩す、試料を回しながら測る、そしてキャピラリー透過法で測ること。前の「透過法」が配向の影響を受けにくいと言ったのは、このためです。強さの比をそのまま結晶形の判定に使うときは、まず配向を疑うのが実務の勘どころです。

この入口のモデルと出典

波の干渉だけに注目した、等間隔の点散乱体1列（1・2・16個）の遠方場モデル。原子間隔4 Å、波長1.5406 Å。等振幅・弾性散乱を仮定し、偏光と原子散乱因子の角度依存は省略。これは結晶全体の粉末パターンではありません。

原子を増やすと図の表示倍率を変えますが、実際の原子間隔は一定です。遠方の検出器は模式的に近く描いています。波の再生は説明用の低速表示で、X線を実際の速さで描いていません。測定強度は時間平均した値です。

計算：各原子の位置 r に対し、位相 = 2π(k入 − k出)・r / λ。各波の複素振幅を足して、その絶対値の二乗を強度とします。比較のため N² で規格化。

IUCr / 波の足し合わせとブラッグの説明

モデルの範囲・式・出典

同じ種類の原子からなる理想的な立方晶の粉末を想定。格子定数 a は単位格子の一辺、結晶子サイズ L は規則正しい並びが続く長さです。粒子全体の大きさとは限りません。図の原子数は模式的です。

ピーク位置：d = a / √(h²+k²+l²)、2d sin θ = λ。波長 λ = 1.5406 Å 固定。グラフは 2θ（入射方向と散乱方向のなす角）。面の番号 (hkl) は原子面の向きを区別する名前です。

強度：F = 1 + t exp[πi(h+k+l)]、面積 ∝ 多重度 × |F|²/(1+t)²。t = 0 は角だけ、t = 1 は同じ原子が体心にもある格子。中間値は体心位置の平均占有率で、散漫散乱は省略。比較のため総散乱能で規格化し、原子散乱因子の角度依存・Lorentz偏光因子・吸収・熱振動は省略しています。実物の強度比を再現する解析ツールではありません。

幅：Scherrer式 β = 0.9λ/(L cos θ) を用い、装置幅 0.12° と二乗和で合成。β は 2θ の半値幅。線形は面積一定のGaussian近似。サイズ以外のひずみ・欠陥も実測ピークを広げます。下段の波は仕組みを伝える模式図で、時間変化する測定信号ではありません。

実験1の波の一致度は、(100)方向の8枚の面に対する波の和から計算。実験3は8枚と24枚の面を比較する説明図で、上のnm値の直接描画ではありません。
